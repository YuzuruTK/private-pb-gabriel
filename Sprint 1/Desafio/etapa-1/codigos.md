## Comandos Utilizados :

- `echo` = Comando utilizado para retornar valores foi usado tanto para indicar o andamento do processo, quanto para inserir coisas dentro de arquivos
- `mkdir` = comando para criar pastas
- `cd` = comando utilizado para se mover dentro das pastas criadas
- `mv` = o comando serve para alterar o path, mas pode ser utilizado para renomea-los tambem
- `touch` = o comando foi utilizado no sentido de criar um arquivo, como ele atualiza a data de alteracao para a de execucao do comando, ele permite criar arquivos desta maneira tambem
- `head` = comando utilizado para as linhas de cima do arquivo
- `tail` = comando utilizado para as linhas de baixo do arquivo
- `cat` = utilizado para retornar todas as linhas do arquivo
- `date` = comando utilizado para retornar a data do sistema
- `rm` = utilizado para remover arquivos
- `zip` = utilizado para compactar um arquivo

## Execucao :

- entre na pasta ecommerce
- adicione um csv com o nome de dados_de_vendas.csv ( este csv precisa estar com o seguinte cabecalho id,produto,quantidade,preço,data ) ;
