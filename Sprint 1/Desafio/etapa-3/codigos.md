## Comandos utilizados

- `ls` - comando utilizado para ver os arquivos que existem dentro da pasta
- `touch` - usado para criar arquivos
- `chmod 664` - usado para dar permissoes para arquivos, especificamente a leitura neste caso
- `echo` - Comando utilizado para retornar valores, foi usado para inserir coisas dentro de arquivos
- `cat` - retorna todo o texto de dentro de um arquivo

## Execucao

- Entre dentro da pasta ecommerce utilizando `cd`
- certifique-se de que existem relatorios a serem consolidados na pasta `vendas/backup/`
- execute o codigo via `sh consolidador_de_processamento_de_vendas.sh`
